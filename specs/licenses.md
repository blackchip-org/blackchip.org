# licenses

This describes the licenses page (licenses.html) for blackchip.org.

Background is black. All content is centered, matching the index page.

A header at the top shows the images/chip100.svg icon above a heading that
reads "Licenses", using the Alfa Slab One font.

Below the header, side by side, is a list box containing all the items
that have a license, and a text panel containing the contents of the
license. These are populated using the licenses.json file found in the
root directory of the repository. The list is sorted alphabetically by
item name.

The "blackchip.org" entry is selected by default, with its license text
already shown in the text panel. Clicking a different item in the list
shows that item's license text instead.

Below that is a link, "Back", that navigates the user back to the index
page when clicked.

Regular body text and the license text use the IBM Plex Sans font.

## Mobile

On a narrow viewport, the list box and text panel stack top to bottom
instead of side by side -- the list on top, the license text below -- so
the list doesn't crowd the text into a sliver.
